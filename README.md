# Phishing Awareness

A web-based phishing awareness project developed as **Task 2 of the CodeAlpha Cybersecurity Internship**.

## About the Project

Phishing is a social engineering attack where attackers attempt to trick users into revealing sensitive information such as passwords, OTPs, banking details, or login credentials.

This project is designed to educate users about phishing attacks and help them recognize suspicious emails, messages, websites, and links.

## Features

- Introduction to phishing
- Common types of phishing attacks
- Phishing warning signs
- Examples of suspicious messages and links
- Phishing prevention tips
- Online safety practices
- Interactive and user-friendly interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
